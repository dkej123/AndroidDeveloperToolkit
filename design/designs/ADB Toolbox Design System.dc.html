ADB Toolbox — Design System

Tokens and controls for an Android Studio tool window plugin. Sized for a 380px right dock: 11–12.5px UI text, 22–26px controls, 4–6px radii, one accent, 1px borders instead of shadows.

Rules
→UI font inherits the IDE font. Never hardcode a webfont — the plugin must follow JBUI.Fonts.label().
→Serials, IPs, ports, package names, densities and log lines are always mono. They are copy-paste targets and need character-level scanning.
→Logcat body is mono 11 / 16px line-height. Line height is fixed so a paused buffer doesn't reflow when severity changes.
→Sentence case everywhere except groupLabel. No title case, no ALL CAPS buttons.
→Numbers in presets keep the multiplication sign (1.15×) and percent (125%) — the unit is the meaning.

Accent blue is only selection, focus and the single primary action in view. Teal is brand — the logo, the tool window icon, the running-command chip — and never a button fill. Amber always means "a non-default value is applied to the device right now", which is why every override row can be reset. Red is only ever destructive: a red control removes data from the device.

05

Surfaces

Four layers. Only the top one casts a shadow.
bg — tool window body, Logcat viewport
panel — section body, device bar
header — toolbars, section headers, status bar
field — sunken input
popup — device picker, app list, confirm, toast
Layout contract
→Device bar is pinned at the top and never scrolls. Status bar is pinned at the bottom.
→The icon rail is a fixed 34px column on the left, full height between the two bars.
→Sections inside a view are separated by a 1px rule, not by cards — cards waste 16px of a 380px dock.
→Inputs are sunken and darker than their panel, so a field is never mistaken for a button.
→Logcat is full-bleed with zero horizontal padding beyond 8px — density beats decoration.

07

Rail, toolbars, tooltips

34px rail, 26px toolbar rows, dividers between action clusters.
Pixel 8 Pro 1A2B3C4D ▾
1 device
The rail carries five views plus Settings pinned to the bottom. A dot on a rail icon means the plugin changed something on the device (amber) or that errors are arriving (red) — the badge is the only reason to leave the current view.
Tooltip
Restart app ⇧⌘R
Force-stops com.acme.shop, then launches its main activity.
Clear app data
Deletes databases, prefs and caches. Signs the user out.
Cannot be undone
Every icon button has a tooltip: verb-first name, shortcut right-aligned, one line of consequence. Destructive tooltips end with the irreversibility note in red.
Icon rules
→16×16 canvas, 1.3–1.4px strokes, 1px grid alignment, round caps, no fills except status dots.
→Monochrome, drawn in textDim and switched to text on hover — color only for state badges.
→1px of padding inside the 16px box so glyphs never touch the hover square.
→No text inside icons, no perspective, no gradients. Two shapes maximum per glyph.
